# Combined datasets for mood-based-music-recommendation-system

This package combines the two uploaded archives in the folder structure expected by the GitHub project.

## Contents
- `data/data.csv` and the other Spotify CSV files: from `archive (1).zip`.
- `data/goemotions/`: all files from `archive.zip`, kept separate from the Spotify CSV files.

## Install into your cloned repository
1. Extract this ZIP in the root of your cloned repository (the same folder as `app.py`).
2. When asked, merge/overwrite the `data` folder. Do not place the files inside an extra nested folder.
3. Commit and push the resulting `data` folder to GitHub.

The current `app.py` expects the Spotify file at `./data/data.csv`, and `DataManager` uses audio-feature columns that are present in this CSV. The GoEmotions files are training data, not a fine-tuned Transformers model directory. The repository's `app.py` separately expects `./fine-tuned-goemotions-model`; this folder is not included in either uploaded ZIP and must be generated by running the fine-tuning notebook or supplied separately.
